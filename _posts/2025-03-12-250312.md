## 불변의 객체 상태로 업데이트하기

### 자바스크립트 기본 유형과 참조 유형의 차이점

✅ 값의 저장 방식과 값의 복사 방식

| 기본 유형 (Primitive Type)                       | 참조 유형 (Reference Type)                                  |
| ------------------------------------------------ | ----------------------------------------------------------- |
| 변수에 실제 값이 저장되는 방식                   | 변수에 값이 아니라 객체의 참조(메모리 주소)가 저장되는 방식 |
| 값 자체를 변경할 수 없다 (불변)                  | 객체의 내부 값을 변경할 수 있다                             |
| 값을 복사, 복사된 값은 원본과는 별개의 값        | 참조(메모리 주소) 복사                                      |
| 스택 메모리에 저장                               | 힙 메모리에 저장                                            |
| number, string, boolean, undefined, null, symbol | 객체, 배열, 함수                                            |

## 리액트에서는 왜 상태를 직접 수정하지 않고 새로운 배열을 만들어 업데이트해야하는가?

리액트는 객체나 배열의 참조 값(메모리 주소)을 기준으로 상태가 변경되었는지를 확인하기 때문에 setState로 업데이트할 때, 이전 상태의 참조 값을 유지하면 React는 변경이 없다고 판단하고 리렌더링을 하지 않는다.

### ✅ 얕은 복사(Shallow Copy)

배열 자체의 참조 값을 변경하기 때문에 배열의 참조 값(배열이 저장된 메모리 주소)이 달라져 리액트가 상태 변경을 감지하고 컴포넌트를 리렌더링!

```javascript
const fruits = ["사과", "바나나", "망고"];
const copyFruits = [...fruits];
```

### ✅ 깊은 복사(Deep Copy)

중첩된 객체 상태 관리, 업데이트
이 부분은 계속 객체의 구조를 푸는 방법이 계속 헷갈린다,, 계속 반복 연습이 필요할 듯!

```javascript
//예를들어 gameBoard 라는 이름으로 INITIAL_GAME_BOARD 중첩 배열을 복사해 새로운 배열을 생성한다면
const INITIAL_GAME_BOARD = [
  [null, null, null],
  [null, null, null],
  [null, null, null],
];

let gameBoard = [...INITIAL_GAME_BOARD].map((value) => [...value]);
// [...INITIAL_GAME_BOARD] 1차 앝은 복사 내부 배열
// map의 value에는 INITIAL_GAME_BOARD의 각 배열들이 순차적으로 들어간다.
// [null, null, null] 들은 이전의 참조값 유지하기 때문에 [...value] 사용해 새로운 참조값을 가진 배열 생성

// 이렇게 객체안에 객체가 있는 형태에서 이름이 홍길동인 사람의 pet의 이름을 변경하려면
const [person, setPerson] = useState({
    name:"홍길동",
    age:30,
    pet:{
        name: "토리"
        age: 3
    },
})
// ...prevPreson 기존 person 객체를 복사
// 기존 pet 객체를 복사하여 새로운 객체를 생성한 후 변경된 name으로 덮어씌어주기
setPerson((prevPreson)=>({...prevPreson, pet : {...prevPreson.pet, name : "똘이" }}))


//그렇다면 배열안의 객체 홍길동의 pet의 age를 업데이트 한다면
const [person, setPerson] = useState([{
    name:"홍길동",
    age:30,
    pet:{
        name: "토리"
        age: 3
    },
},{
    name:"이나나",
    age:25,
    pet:{
        name: "멍멍"
        age: 5
    },
}])

//map은 기존 배열을 복사하여 새로운 배열을 반환하기 때문에 prevPerson의 참조값이 변경된다.
setPerson((prevPreson)=> prevPreson.map((person)=>{
    if(person.name === "홍길동"){
       return {...person, pet : {...person.pet, age: 5}}
    }else return person
}))

//객체 안의 배열
const [person, setPerson] = useState({
    name:"홍길동",
    age:30,
    pet:[
    {
     name: "토리"
     age: 3
    },
    {
     name: "똘이"
     age: 10
    }
    ]
})
//pet의 name이 토리인 name을 업데이트 한다면
//pet은 person.pet의 배열
setPerson((prevPerson) => ({
  ...prevPerson,
  //map 자동으로 새로운 배열 반환
  pet: prevPerson.pet.map((obj) => obj.name === "토리" ? { ...obj, name: "톰" } : obj ),
}));

```
