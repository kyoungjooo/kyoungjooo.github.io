## 리엑트란?

- 사용자 인터페이스를 만들기 위한 자바스크립트 라이브러리<br>
- 리엑트는 브라우저의 자바스크립트를 이용해 데이터가 변경됨에 따라 적절한 컴포넌트만 재로딩 없이 효율적으로 렌더링 한다.

<https://ko.legacy.reactjs.org/docs/getting-started.html>

## 왜 리엑트를 사용하는가?

- 직접적인 Dom 조작을 최소화하며, 가상돔을 사용해 변경된 부분만 업데이트, 렌더링하기 때문에 빠르고 최적화
- 컴포넌트라는 UI를 구성하는 재사용 가능한 코드 블록을 사용해 효율적인 UI 개발과 유지보수에 용이

<br>

| 구분          | 리엑트 React                                   | 자바스크립트 Javascript                               |
| ------------- | ---------------------------------------------- | ----------------------------------------------------- |
| 정의          | JavaScript 기반의 UI 라이브러리                | 웹 개발을 위한 프로그래밍 언어                        |
| 코드작성      | 선언형 코드 작성<br>목표로 하는 ui 상태를 정의 | 명령형 코드 작성<br>목표가 아닌 거쳐야 할 단계를 정의 |
| DOM 조작 방식 | 가상 DOM(Virtual DOM) 사용                     | 직접 HTML 요소를 선택 후 변경                         |
